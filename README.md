# Token Radar

A token launch radar: it reads a sealed snapshot of every protocol DefiLlama tracks, finds the ones that still record no token and are not a wrapped or staked product of one that trades, and ranks them by an implied launch value from their TVL, seven-day growth and age with no token. The dashboard shows the board, a detail view for every protocol and the steps to farm it. Node 22, standard library only.
